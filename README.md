# Olist Retention Analysis

Why don't customers come back to a Brazilian e-commerce marketplace?

I'm using Olist's public dataset (about 100k orders, 9 tables) to find out. The goal is to trace what happens between a customer's first order and the silence after it: late deliveries, bad reviews, high shipping costs. Then I'll suggest a fix the business could actually build.

**Tools:** PostgreSQL, SQL, Power BI

**Status:** schema, data load and ERD done. Analysis in progress.
